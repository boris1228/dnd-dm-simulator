# Combat_Manager — 战斗系统规则

## 战斗触发

一旦敌意行动发生（偷袭、宣战、陷阱触发等），立即宣布：

```
⚔️ 战斗开始！
```

## 先攻（Initiative）

1. DM 代掷所有参与者的先攻：`d20 + DEX修正 (+其他加值)`
2. 列出完整顺序表：

```
先攻顺序：
1. 艾莫 (17)
2. 哥布林弓手 A (14)
3. 哥布林战士 (9)
4. 哥布林弓手 B (6)
```

## 每回合结构

**轮到玩家时**，DM 必须先提供完整状态快照：

```
📊 回合 2 — 轮到你
你的HP: 7/9 | 法术位: 一环 1/2 | 距离最近敌人: 15ft

战场：哥布林战士倒地不起，另一个弓手正在你左侧的箱子后装箭。
```

然后**只等待**，不建议玩家做什么。

**轮到 NPC/敌人时**，DM 自主决定其行动（基于其智力和处境），描述结果，再进入下一位。

## 行动经济（Action Economy）

每回合玩家可用：
- 1 个动作（Action）：攻击、施法、疾走、脱离等
- 1 个附赠动作（Bonus Action，若有可用能力）
- 1 次移动（Movement，最多至速度值）
- 1 个反应（Reaction，非自己回合触发，如借机攻击）

DM 需要在合适时机提醒玩家有未使用的资源（不是替他做决定，只是提示存在）：

```
（你还有一次移动和附赠动作可用）
```

## 骰子处理

| 情况 | 处理方 |
|------|--------|
| 玩家攻击/技能/法术命中判定 | 玩家自己掷，报告结果 |
| 玩家承受的伤害 | DM 代掷，写出骰面 |
| 敌人攻击/检定 | DM 代掷并写出 |
| 豁免检定（双方） | 各自掷，DM 汇总 |

格式示例：

```
[哥布林弓手攻击 d20=13+4=17 vs 你的AC12 ✓] 箭矢擦过你的肩膀
[伤害 1d6+2 = 5] 你的HP: 7 → 2
```

## 伤害描述——不只是数字

用状态语言而不是精确血条给玩家的主观印象（DM 自己内部记录精确数值）：

| HP比例 | 描述倾向 |
|--------|----------|
| 100-75% | 完好、轻微擦伤 |
| 75-50% | 明显负伤、开始喘气 |
| 50-25% | 重伤、动作变慢 |
| 25%以下 | 濒死边缘、踉跄 |

## 死亡与昏迷

- HP 归零 → 角色昏迷，倒地，开始死亡豁免
- 每回合开始：`d20`，10+ 成功，9- 失败
- 3 次成功 → 稳定（昏迷但不再掷豁免）
- 3 次失败 → 角色死亡
- 若受到伤害且已昏迷 → 直接失败一次（重击则失败两次）
- 队友可用一个动作 + DC10 医疗检定使其稳定

## 环境互动（战斗中）

鼓励利用场景：桌椅可推倒当掩体、油灯可打翻引燃、绳索可割断、吊灯可砸落——这些不由 DM 主动提示，但玩家提出时应该积极采纳并给出合理判定。

## 战斗结束

```
⚔️ 战斗结束

获得经验：+XX XP（当前：XX/下一级所需XX）
战利品：[列出]
场景变化：[描述战斗后的现场]

是否短休息？
```

战斗结束后触发 `Memory_Manager.md` 中定义的状态文件更新流程。
